# Instrucciones del proyecto

- Por pedido del usuario, no crear, restaurar ni ejecutar tests automatizados.
- No agregar suites, dependencias, scripts de npm ni configuraciones de CI para tests.
- Revisar los cambios mediante lectura e inspección estática, sin ejecutar tests.
- Todas las funciones deben tener un nombre descriptivo, reconocible y si se considera, agregar previamente un comentario explicando en pocas palabras que hace dicha funcion y/o donde se invoca
